STATUS
Draft source-build recipe, not built or GPU-tested by Codex.
No compute job has been submitted. This is an experiment runtime subset,
not a complete reconstruction of every distribution in requirements_all.txt.

PRESERVED
PyTorch 2.1.2, CUDA toolkit 12.1.1, NumPy 1.25.1, SciPy 1.11.1,
pandas 2.0.3, scikit-learn 1.4.2, einops 0.7.0, matplotlib 3.7.2,
and pinned runtime dependencies listed in requirements-runtime.txt.
psutil 5.9.5 is compiled from source because that release lacks an ARM wheel.

ASSUMPTIONS AND DEVIATIONS
Python 3.11.3 is inferred from the original 2023a module toolchain.
Pillow 10.0.0 is provisional: requirements_all.txt also lists 9.5.0.
pyparsing 3.0.9 replaces exported 3.1.0 to satisfy matplotlib metadata.
cuDNN 8.9.2.26 is a selected CUDA-12.1-compatible ARM release; the original
version has not been established. Obtain the old recipe if exact matching matters.
GCC 11 / Ubuntu 22.04 / OpenBLAS differ from the original GCC-12.3.0 stack.
oneDNN/MKLDNN CPU acceleration is disabled. NCCL comes from the PyTorch source
build; its actual version is reported by smoke_gpu.py.
PyTorch bundle extras (torchvision, torchtext, torchaudio, torchdata, Ignite,
profiler) are omitted because the inspected training/testing imports do not
require them. This does not reproduce their original presence.
MNE preprocessing and optional UMAP plotting are not covered: their versions
are absent from the export. Use the original preprocessed datasets for comparisons.
Triton / torch.compile and multi-node Slingshot communication are not validated.
